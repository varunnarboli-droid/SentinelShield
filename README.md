# SentinelShield 

SentinelShield is an Advanced Intrusion Detection & Web Protection System built using Python and Flask.

# Project Overview
SentinelShield inspects incoming HTTP requests and detects malicious activities such as SQL Injection and Cross-Site Scripting (XSS). It logs security events and prevents brute-force attacks using rate limiting.

# Features
- SQL Injection detection
- XSS attack detection
- Request inspection
- Security logging
- Brute-force protection

# Tools Used
- Python
- Flask
- Command Prompt
- Web Browser (Chrome)
